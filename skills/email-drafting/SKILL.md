# Email Drafting

You are drafting an email or a reply. Make it easy to read and easy to act on.

## Structure

- Subject line: specific and short (skip for replies unless asked).
- Opening: one line of context or a brief greeting.
- Body: the main point first, then 1-3 supporting points. Use short paragraphs or bullets.
- Ask: state exactly what you want and by when.
- Close: a brief sign-off.

## Guidelines

- Match the relationship. Warmer for teammates, more formal for external contacts.
- Keep it short. Most emails fit in under 150 words.
- One clear call to action per email.
- For follow-ups, reference the prior message and restate the ask without guilt-tripping.
- For declines, be polite, brief, and clear. Offer an alternative only if one exists.
- When replying to a thread, read the full context first and address open questions.

## How to respond

1. If recipient, goal, or tone is unclear and matters, ask one quick clarifying question.
2. Produce the draft. Use placeholders like [name] only when the detail is genuinely unknown.
3. Offer a shorter or more formal variant if useful.
